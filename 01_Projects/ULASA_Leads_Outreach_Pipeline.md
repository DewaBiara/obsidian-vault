## 🔄 Sales Funnel Stages

```
[1. Uncontacted] ──> [2. Initial Outreach] ──> [3. Pitch / Demo Kit] ──> [4. Trial (7 Hari)] ──> [5. Closed Won / Deal]
                             │
                             └──> [Cold / Not Interested]
```

1. **Uncontacted:** Data tersaring di database master.
2. **Initial Outreach:** Kontak pertama via WhatsApp Bisnis, Instagram DM, atau On-site visit kasir.
3. **Pitch / Demo Kit:** Menunjukkan sampel fisik Smart NFC Stand (Kayu Jati / Akrilik Hitam) dan demo tap ke smartphone owner/manager.
4. **Trial (7 Hari):** Pemasangan 1-2 unit prototype di meja kasir untuk uji coba interaksi pelanggan.
5. **Closed Won / Deal:** Pembelian batch unit + aktivasi langganan dynamic portal.
